# Pulse Plugin Studio

**Pulse Plugin Studio** — отдельная программа для создания, редактирования и проверки плагинов FunPay Pulse SDK. Заменяет консоль на программу удобную

## Возможности

* создание SDK-плагинов;
* импорт папки проекта, `.zip`, `.fppkg`, `.fqq`;
* удобный редактор кода;
* дерево файлов и вкладки открытых файлов;
* создание, переименование и удаление файлов/папок;
* запуск `check`, `test`, `doctor`, `pack`, `dry-run`;
* автоопределение trusted-плагинов;
* фикс ошибки SSL / certifi;
* просмотр собранных `.fppkg` пакетов.

## Как использовать

1. Скачай последнюю версию из **Releases**.
2. Запусти `Pulse Plugin Studio.exe`.
3. Создай новый плагин или импортируй существующий проект.
4. Отредактируй файлы.
5. Запусти проверки SDK.
6. Собери `.fppkg` для отправки на review.

## Требования

* Windows 10/11
* Python 3.10 или новее

## Важно

Программа не обходит подписки, покупки, review или серверные проверки FunPay Pulse.
Это инструмент для разработки и тестирования своих SDK-плагинов.
